# Nicolette Mtisi: Data Science & Analytics Portfolio

🌐 **Live site: [nic-stack.github.io/NicoletteMtisi](https://nic-stack.github.io/NicoletteMtisi/)**

This is the source code for my personal portfolio website, which showcases my work in machine learning, NLP, business intelligence and data engineering.

## Sections
- **About:** who I am and what I work on, with animated highlight stats
- **Experience & Education:** a timeline of roles and measurable achievements, plus my M.S. in Data Analytics & Visualization (Yeshiva University) and B.Sc. in Data Science & Informatics (University of Zimbabwe)
- **Projects:** project cards with filters (Power BI, NLP & AI, Machine Learning, Data Engineering) linking to GitHub repos, live demos and dashboards, and Medium write-ups
- **Skills:** my technical toolkit grouped by category
- **Contact:** a working contact form, plus a downloadable resume

## Built With
- **HTML5 and CSS3:** custom responsive layout with a warm, neutral color palette (cream, sand, espresso, rust)
- **Vanilla JavaScript:** sticky navigation, mobile menu, project filtering, scroll-triggered fade-ins and count-up stats
- **Google Fonts:** DM Serif Display for headings and DM Sans for body text
- **Font Awesome:** icons
- **Web3Forms:** contact form submissions
- **GitHub Pages:** hosting

## Run Locally
It's a static site, so there's no build step:
```bash
git clone https://github.com/nic-stack/NicoletteMtisi.git
cd NicoletteMtisi
open index.html
```
